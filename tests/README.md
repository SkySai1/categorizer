# Руководство по запуску тестов

Этот проект использует `pytest` для тестирования. Следуйте инструкциям ниже, чтобы запустить тесты.

---

## **Установка зависимостей**
Убедитесь, что все зависимости установлены. Если нет, выполните:
```bash
pip install -r requirements.txt
```

---

## **Запуск тестов**

### 1. Запуск всех тестов
Для запуска всех тестов в папке `tests` выполните:
```bash
pytest
```

### 2. Подробный вывод
Для отображения подробных результатов тестирования:
```bash
pytest -v
```

### 3. Запуск конкретного файла тестов
Чтобы запустить тесты из определённого файла, используйте:
```bash
pytest tests/test_url_handler.py
```

### 4. Запуск конкретного теста
Для запуска конкретного теста используйте ключ `-k` с именем теста:
```bash
pytest -k test_fetch_url_content_success
```

---

## **Создание отчётов**

### JUnit-отчёт
Для создания отчёта в формате JUnit выполните:
```bash
pytest --junitxml=report.xml
```
Это создаст файл `report.xml` с результатами тестирования.

### Проверка покрытия кода
Установите `pytest-cov` для проверки покрытия:
```bash
pip install pytest-cov
```
Запустите тесты с генерацией отчёта о покрытии:
```bash
pytest --cov=app
```

---

Теперь вы готовы запускать тесты и анализировать результаты!
