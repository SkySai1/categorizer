# Проект: Сервис категоризации интернет-ресурсов

## Описание
Этот проект представляет собой Python-приложение для обработки списка URL-адресов, извлечения текстовой информации с этих страниц, и последующей категоризации с использованием OpenAI GPT. 

### Основные функции:
- Обход заданного списка URL-адресов.
- Извлечение текстовых блоков и заголовков (title) с каждой страницы.
- Классификация страниц на основе переданных категорий.
- Генерация CSV-файла с результатами (URL, категория, title).
- Конфигурация через `settings.py`.

---

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   cd <папка_репозитория>
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте `settings.py` с вашим API-ключом OpenAI и другими параметрами.

## Ключевые файлы

### 1. Основные файлы
- **`main.py`**: Точка входа. Обрабатывает входные файлы (список URL и категорий), вызывает модули, сохраняет результаты в CSV.
- **`settings.py`**: Конфигурационный файл. Содержит:
  - API ключ для работы с ChatGPT.
  - Шаблон промпта.
  - Таймауты и параметры сети.

### 2. Логика приложения (`services/`):
- **`url_handler.py`**: 
  - Загружает страницы по URL.
  - Имитация действий пользователя (заголовки, задержки, обработка `robots.txt`).
  - Извлекает `title` страниц.
- **`text_extractor.py`**: 
  - Структурирует текстовые блоки для дальнейшей обработки.
  - Убирает лишний HTML и ненужные элементы.
- **`categorizer.py`**: 
  - Работает с API ChatGPT.
  - Передаёт текстовые данные и категории, получает результат классификации.
- **`file_handler.py`**: 
  - Парсит входные TXT-файлы (список URL и категории).
  - Генерирует итоговый CSV-файл с полями `URL`, `категория`, `title`.

### 3. Тесты (`tests/`):
- **`test_url_handler.py`**: Проверяет корректность обхода URL и извлечения `title`.
- **`test_text_extractor.py`**: Проверяет корректность извлечения текстовых блоков из HTML.
- **`test_categorizer.py`**: Проверяет запросы к ChatGPT и получение правильных категорий.
- **`test_file_handler.py`**: Проверяет чтение TXT-файлов и генерацию корректного CSV.
- **`test_main.py`**: Интеграционные тесты для проверки полного процесса обработки.
- **`data/`**:
  - **`test_urls.txt`**: Пример файла со списком URL для тестов.
  - **`test_categories.txt`**: Пример файла со списком категорий для тестов.

---

## Использование
1. Запустите приложение через командную строку, указав входные файлы:
   ```bash
   python app/main.py <путь_к_URL_файлу> <путь_к_категориям_файлу>
   ```

2. Результат будет сохранён в папке `output/result.csv`.
